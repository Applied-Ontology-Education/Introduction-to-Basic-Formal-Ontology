Structure
15-week learning path

01

A framework for representing reality

BFO provides a shared upper-level architecture for domain ontologies. It helps ontology developers represent entities consistently and connect knowledge across otherwise separate information systems.

This course moves from BFO's core distinctions and realist foundations to OWL and first-order logic, then into applications spanning scientific, industrial, biomedical, and government domains.
